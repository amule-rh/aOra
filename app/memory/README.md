# aOra memory

This directory stores the athlete's persistent working memory:

- `profile.json` — athlete profile and constraints.
- `routine.json` — current program / sessions.
- `progress.json` — metrics, personal bests and recovery observations.
- `history.md` — human-readable training history.

## Privacy

Do not store medical records, diagnoses, passwords, API keys or other sensitive secrets here.

If this repository is public, these files are public. For private athlete data, use a private GitHub repository and a hosting option that supports deploying from a private repository, such as Cloudflare Pages.
